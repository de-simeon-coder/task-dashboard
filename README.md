# 📝 Personal Task Dashboard

![GitHub repo size](https://img.shields.io/github/repo-size/de-simeon-coder/task-dashboard?style=flat-square)

A modern, responsive, and feature-rich Web Task Dashboard built with plain HTML, CSS, and vanilla JavaScript. Developed entirely on Android via Termux.

## 🚀 Live Demo
[View Live Application](https://de-simeon-coder.github.io/task-dashboard/)

## ✨ Features
- **Local Persistence:** Retains user name and tasks using `localStorage`.
- **Dark Mode Toggle:** Smooth theme transition saved to browser preferences.
- **Task Analytics:** Displays Total, Active, and Completed task statistics.
- **Task Management:** Create, inline edit, complete, drag-reorder, and delete tasks.
- **Categories & Priority:** Categorize tasks (Study, Work, Personal) with colored badges.
- **Due Dates & Alerts:** Track deadlines with visual overdue indicators.
- **Live Search & Filters:** Real-time search by text or category and status filtering.
- **Import / Export:** Export task lists to JSON or CSV and restore from JSON backups.
- **Audio Feedback:** Synthesizer feedback using the Web Audio API on task completion.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Variables, Flexbox, Mobile-first Layout)
- Vanilla JavaScript (ES6+, LocalStorage API, Drag-and-Drop API, Web Audio API)
