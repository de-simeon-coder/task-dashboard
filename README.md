# 📝 Personal Task Dashboard

A modern, responsive, and feature-rich Web Task Dashboard built with plain HTML, CSS, and vanilla JavaScript[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).

[View Live Project](https://de-simeon-coder.github.io/task-dashboard/)

## ✨ Key Features
- **Local Persistence:** Retains user name and tasks using `localStorage`[span_2](start_span)[span_2](end_span).
- **Dark Mode Toggle:** Smooth theme transition stored in user preferences[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span).
- **Task Management:** Create, inline edit, complete, and delete tasks.
- **Categories & Priority:** Categorize tasks (Study, Work, Personal) with colored badges and set priority levels[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
- **Due Dates & Overdue Alerts:** Tracks task deadlines with visual overdue badges.
- **Live Search & Filters:** Filter tasks by status (All, Active, Completed) or search by keyword[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
- **Drag-and-Drop Reordering:** Easily rearrange task order.
- **Import / Export Data:** Export task lists to JSON or CSV and import existing backups.
- **Sound Effects & Progress Tracker:** Web Audio API feedback on completion and visual progress bar[span_9](start_span)[span_9](end_span).

## 🛠️ Built With
- HTML5
- CSS3 (Variables, Flexbox)
- JavaScript (Vanilla, LocalStorage API, Web Audio API)
